# Глава 7. Рецепты: где что поменять

Шпаргалка по самым частым правкам. Подробности о каждом параметре есть в главах,
на которые даны ссылки; как запускать сценарии целиком — в [RUN_SCENARIOS.md](RUN_SCENARIOS.md).
Номера строк актуальны на 2026-11-13. Если строка «уехала», ищи по имени параметра
(`grep -n spawn_x ...`).

> Пересобирать после правок **не нужно** (сборка с `--symlink-install`):
> перезапусти launch. Исключение — новые файлы ([глава 0](00-введение.md#04-сборка-и-запуск)).

## 7.1. Положение тележки на старте

**Без правки кода** — аргументами запуска:

```bash
ros2 launch cart_xarm_bringup cart_xarm6_gz.launch.py spawn_x:=-0.3 spawn_y:=0.2 spawn_yaw:=1.5708
```

**Изменить значение по умолчанию:**
[cart_xarm6_gz.launch.py:55-59](../src/r2_robot/cart_xarm_bringup/launch/cart_xarm6_gz.launch.py#L55-L59)

| Аргумент | По умолчанию | Смысл |
|---|---|---|
| `spawn_x` | `-0.5` | позиция по X в мире, м (отодвинута от стола) |
| `spawn_y` | `0.0` | позиция по Y в мире, м |
| `spawn_z` | `0.07` | высота спавна (чтобы колёса не провалились в пол) |
| `spawn_yaw` | `0.0` | поворот вокруг вертикали, рад (1.5708 = 90°) |

Стол стоит при x = 1.05 (ближний край x = 0.45), поэтому тележку `c2l-v3` ставь так,
чтобы корпус не пересекал стол. В навигации (`cart_nav_gz`) своя точка по умолчанию:
`spawn_x:=-2.0` в комнате `cart_nav.world`. Подробнее в [главе 2](02-cart_xarm_bringup.md).

## 7.2. Где стоит рука на тележке (точка крепления)

| Модель тележки | Файл | Значение сейчас |
|---|---|---|
| `c2l-v3` | [c2l-v3.urdf.xacro:9](../src/r2_robot/quasi_cart_description/urdf/c2l-v3.urdf.xacro#L9) | `arm_mount_xyz = -0.25 -0.1295 0.849` |

**Временно сдвинуть или повернуть руку без правки файлов:**

```bash
ros2 launch cart_xarm_bringup cart_xarm6_gz.launch.py arm_offset_xyz:="0.05 0 0" arm_offset_rpy:="0 0 3.1416"
```

Подробнее в [главе 1](01-quasi_cart_description.md) и [CART_MODELS.md](CART_MODELS.md).

## 7.5. Тележка без руки (лёгкая симуляция)

Для езды и парковки рука не нужна, а грузит процессор больше чем вдвое:

```bash
ros2 launch cart_xarm_bringup cart_xarm6_gz.launch.py arm:=false     # тележка без руки
ros2 launch cart_xarm_bringup cart_nav_gz.launch.py                  # навигация: без руки по умолчанию
ros2 launch cart_xarm_bringup cart_nav_gz.launch.py arm:=true        # навигация с рукой (на тормозе)
```

При `arm:=false` в модели нет руки, камеры запястья и вакуума (xacro `with_arm:=false`), не
запускаются контроллеры руки, парковка, MoveIt и ноды захвата. Датчики тележки (лидар, ToF,
IMU `/imu`, передняя камера) работают как обычно. Только модель, без Gazebo:

```bash
xacro $(ros2 pkg prefix quasi_cart_description)/share/quasi_cart_description/urdf/cart_with_arm.urdf.xacro \
  with_arm:=false > /tmp/cart_only.urdf && check_urdf /tmp/cart_only.urdf
```

Подробнее — [глава 2, §3.14](02-cart_xarm_bringup.md#314-тележка-без-руки-armfalse).

## 7.8. Вакуумная присоска

- Включить или выключить:
  `ros2 service call /vacuum_gripper/set std_srvs/srv/SetBool "{data: true}"`
  или `ros2 topic pub --once /vacuum_gripper/cmd std_msgs/msg/Bool "{data: true}"`.
- Допуски «касания»: параметры `contact_distance` (0.015 м) и `max_angle_deg` (20)
  ноды [vacuum_gripper_sim.py](../src/xarm_grasping/scripts/vacuum_gripper_sim.py). На лету:
  `ros2 param set /vacuum_gripper_sim contact_distance 0.03`.
- Подвести TCP к точке без MoveIt: `arm_goto_tcp.py` ([глава 4](04-xarm_grasping.md)).
- Подробно о вакууме, кнопке в RViz и «взяли или нет» — [глава 9](09-вакуум-кнопка-готовность.md).

## 7.9. Анализатор захвата (тележка)

Главный launch передаёт ноде значения для сцены с тележкой:
`table_height=0.015`, `block_x=1.14`, `block_y=0.135`
([cart_xarm6_gz.launch.py:400-402](../src/r2_robot/cart_xarm_bringup/launch/cart_xarm6_gz.launch.py#L400-L402)).
Они посчитаны в комментарии над нодой (строки 374-380) от измеренной позы `link_base`
в мире ≈ (-0.54, -0.135, 0.910) при спавне в (-0.3, 0). ⚠️ Сейчас `spawn_x` по умолчанию
`-0.5`, так что `block_x` устарел на ~0.2 м; он нужен только при `use_prior_pose:=true`.
Сменил тележку или точку спавна — пересчитай.
Дефолты в самом коде [grasp_analyzer.py](../src/xarm_grasping/scripts/grasp_analyzer.py):
`table_height` (строка 73, 1.0), `block_x`/`block_y` (115-116) — действуют только при ручном
запуске ноды. Подробнее в [главе 4](04-xarm_grasping.md).

## 7.10. Запуск без графики / на слабом ПК

```bash
ros2 launch cart_xarm_bringup cart_xarm6_gz.launch.py headless:=true use_rviz:=false gripper_camera_preview:=true
```

- `use_moveit:=false` отключает MoveIt;
- `manipulation_nodes:=false` — без нод захвата (вакуум, `grasp_analyzer`, облако камеры запястья);
- `front_camera:=false` — без передней камеры;
- `arm:=false` — без руки вообще (7.5).

Для навигации рекомендуется `headless:=true`, ещё легче — `use_octomap:=false` ([NAV.md](NAV.md)).

## 7.12. Пределы суставов, скорость, планировщик

- Пределы суставов в URDF: `xarm_description/urdf/xarm6/xarm6.urdf.xacro`
  и `xarm6.ros2_control.xacro` (записаны в двух местах).
- Скорости и ускорения для MoveIt: `xarm_moveit_config/config/xarm6/joint_limits.yaml`.
- Контроллеры руки в симуляции на тележке и на столе:
  `quasi_cart_description/config/xarm6_controllers_sim.yaml` (частота 150 Гц, только
  `position`); для железа — `xarm_controller/config/xarm6_controllers.yaml`.
- Тормоз руки: `cart_xarm_bringup/config/arm_hold.yaml`.

⚠️ MoveIt строит **свою** модель руки, без тележки. Изменения URDF
руки нужно повторить и там ([глава 6](06-xarm_ros2.md)).
