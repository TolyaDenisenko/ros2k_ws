# Глава 7. Рецепты: где что поменять

Шпаргалка по самым частым правкам. Подробности о каждом параметре есть в главах,
на которые даны ссылки. Номера строк актуальны на 2026-10-20. Если строка
«уехала», ищи по имени параметра (`grep -n spawn_x ...`).

> Пересобирать после правок **не нужно** (сборка с `--symlink-install`):
> перезапусти launch. Исключение — новые файлы ([глава 0](00-введение.md#04-сборка-и-запуск)).

## 7.1. Положение тележки на старте

**Без правки кода** — аргументами запуска:

```bash
ros2 launch cart_xarm_bringup cart_xarm6_gz.launch.py spawn_x:=-0.3 spawn_y:=0.2 spawn_yaw:=1.5708
```

**Изменить значение по умолчанию:**
[cart_xarm6_gz.launch.py:55-59](../../src/r2_robot/cart_xarm_bringup/launch/cart_xarm6_gz.launch.py#L55-L59)

| Аргумент | По умолчанию | Смысл |
|---|---|---|
| `spawn_x`, `spawn_y` | `0.0` | позиция в мире, м |
| `spawn_z` | `0.07` | высота спавна (чтобы колёса не провалились в пол) |
| `spawn_yaw` | `0.0` | поворот вокруг вертикали, рад (1.5708 = 90°) |

Стол стоит при x = 1.05, поэтому тележку `c2l-v3-scaled` ставь так, чтобы
корпус не пересекал стол. Подробнее в [главе 2](02-cart_xarm_bringup.md).

## 7.2. Где стоит рука на тележке (точка крепления)

| Модель тележки | Файл | Значение сейчас |
|---|---|---|
| `c2l-v3`, `c2l-v3-scaled` | [c2l-v3.urdf.xacro:14](../../src/r2_robot/quasi_cart_description/urdf/c2l-v3.urdf.xacro#L14) | `arm_mount_xyz = -0.25 -0.1295 0.849` |
| `c2` и все без своего значения | [cart-arm.xacro:42](../../src/r2_robot/quasi_cart_description/urdf/cart-arm.xacro#L42) | `-0.0075 0.0 0.849` |

`x` — вдоль тележки (+ вперёд, − к ручке), `y` — вбок (+ влево), `z` — высота крыши.

**Временно сдвинуть или повернуть руку без правки файлов:**

```bash
ros2 launch cart_xarm_bringup cart_xarm6_gz.launch.py arm_offset_xyz:="0.05 0 0" arm_offset_rpy:="0 0 3.1416"
```

Подробнее в [главе 1](01-quasi_cart_description.md).

## 7.3. Начальная поза руки (углы суставов)

- Gazebo:
  [cart_xarm6_gz.launch.py:67](../../src/r2_robot/cart_xarm_bringup/launch/cart_xarm6_gz.launch.py#L67),

- Рука одна на столе:
  [xarm6_gz.launch.py:162](../../src/xarm_gz_bringup/launch/xarm6_gz.launch.py#L162).

## 7.4. Модель тележки

`robot_model:=c2l-v3-scaled` (по умолчанию) или `robot_model:=c2`.
Дефолт задан в [cart_xarm6_gz.launch.py:366](../../src/r2_robot/cart_xarm_bringup/launch/cart_xarm6_gz.launch.py#L366),
в `cart_xarm6_rviz.launch.py` и в
[cart_with_arm.urdf.xacro:21](../../src/r2_robot/quasi_cart_description/urdf/cart_with_arm.urdf.xacro#L21).
Масштаб корпуса задан в
[c2l-v3-scaled.urdf.xacro:17-18](../../src/r2_robot/quasi_cart_description/urdf/c2l-v3-scaled.urdf.xacro#L17-L18).
Таблица всех моделей лежит в `CART_MODELS.md`.

## 7.5. Стол, коробка, цилиндр в мире

Файл [cart_table_offline.world](../../src/r2_robot/cart_xarm_bringup/worlds/cart_table_offline.world):

| Объект | Строка | Поза сейчас (x y z r p y) |
|---|---|---|
| стол | [42](../../src/r2_robot/cart_xarm_bringup/worlds/cart_table_offline.world#L42) | `1.05 0 0`, верх столешницы z = 0.925 |
| `pick_box` | [108](../../src/r2_robot/cart_xarm_bringup/worlds/cart_table_offline.world#L108) | `0.60 0 0.9505` |
| `cylinder_block` | [144](../../src/r2_robot/cart_xarm_bringup/worlds/cart_table_offline.world#L144) | `0.80 -0.28 0.9705` |

Если двигаешь стол по высоте, подними и объекты на нём. Если переименовываешь
`pick_box`, поменяй и `vacuum_target_model` в `cart-arm.xacro`, и параметр ноды
вакуума в launch ([глава 4](04-xarm_grasping.md)).

⚠️ Плагин **Sensors** объявляется только в мире. Не добавляй его в модель робота,
иначе Gazebo упадёт с `Scene already exists`.

## 7.6. Камера на запястье

| Хочу | Где |
|---|---|
| Сдвинуть или повернуть камеру | [gripper_camera.xacro:21](../../src/r2_robot/quasi_camera_description/urdf/gripper_camera.xacro#L21), `mount_xyz='0.075 0 0.030'`, `mount_rpy` |

Подробнее в [главе 3](03-quasi_camera_description.md).

## 7.7. Вакуумная присоска

- Включить или выключить:
  `ros2 service call /vacuum_gripper/set std_srvs/srv/SetBool "{data: true}"`.
- Допуски «касания»:
  [vacuum_gripper_sim.py:98-100](../../src/xarm_grasping/scripts/vacuum_gripper_sim.py#L98-L100)
  (`contact_distance` 0.015 м, `max_angle_deg` 20). На лету:
  `ros2 param set /vacuum_gripper_sim contact_distance 0.03`.
- Подвести TCP к точке без MoveIt: `arm_goto_tcp.py` ([глава 4](04-xarm_grasping.md)).

## 7.8. Анализатор захвата

[grasp_analyzer.py](../../src/xarm_grasping/scripts/grasp_analyzer.py):
`table_height` (строка 73, по умолчанию 1.0), `block_x`/`block_y` (95-96).
⚠️ Главный launch их не передаёт, поэтому работают значения по умолчанию из кода. Подробнее в [главе 4](04-xarm_grasping.md).

## 7.9. Запуск без графики / на слабом ПК

```bash
ros2 launch cart_xarm_bringup cart_xarm6_gz.launch.py headless:=true use_rviz:=false gripper_camera_preview:=true
```

`use_moveit:=false` отключает MoveIt.

## 7.10. Рука одна на столе (`xarm_gz_bringup`)

Поза спавна задана в
[xarm6_gz.launch.py:72](../../src/xarm_gz_bringup/launch/xarm6_gz.launch.py#L72),
`-x 0 -y -0.84 -z 0`. ⚠️ Комментарий там говорит о столешнице (z = 1.015), а
значение сейчас 0. Если рука должна стоять на столе, поставь `-z 1.015`.
Подробнее в [главе 5](05-xarm_gz_bringup.md).

## 7.11. Пределы суставов, скорость, планировщик

- Пределы суставов в URDF: `xarm_description/urdf/xarm6/xarm6.urdf.xacro`
  и `xarm6.ros2_control.xacro` (записаны в двух местах).
- Скорости и ускорения для MoveIt: `xarm_moveit_config/config/xarm6/joint_limits.yaml`.
- Частота контроллеров: `xarm_controller/config/xarm6_controllers.yaml`.

⚠️ MoveIt строит **свою** модель руки, без тележки и камеры. Изменения URDF
руки нужно повторить и там ([глава 6](06-xarm_ros2.md)).
