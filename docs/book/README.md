# Книга по проекту ros2k_ws

Учебник для начинающих: что лежит в каждой папке проекта, что прописано в
файлах и где что менять.

| Глава | Тема |
|---|---|
| [0. Введение](00-введение.md) | словарь терминов, карта папок, сборка, когда нужна пересборка |
| [1. quasi_cart_description](01-quasi_cart_description.md) | модели тележек, URDF/xacro, крепление руки, вакуум (DetachableJoint) |
| [2. cart_xarm_bringup](02-cart_xarm_bringup.md) | главный launch по шагам, все аргументы, мир, мосты gz↔ROS, RViz |
| [3. quasi_camera_description](03-quasi_camera_description.md) | камера Orbbec на запястье, TF, сенсор gz, облако точек |
| [4. xarm_grasping](04-xarm_grasping.md) | grasp_analyzer, симуляция вакуума, arm_goto_tcp |
| [5. xarm_gz_bringup](05-xarm_gz_bringup.md) | рука одна на столе |
| [6. xarm_ros2](06-xarm_ros2.md) | форк UFactory: описание руки, контроллеры, MoveIt |
| [7. Рецепты](07-рецепты.md) | **шпаргалка: где поменять положение тележки, руки, стола, камеры** |
| [8. Рука на столе](08-рука-на-столе.md) | отдельный пример без тележки: модель, мир, 8 объектов из одного YAML, кронштейн камеры, поза наблюдения, свет |
| [9. Вакуум, кнопка, готовность](09-вакуум-кнопка-готовность.md) | вакуум на несколько объектов, проверка касания, кнопка в RViz, «можно ли брать» |
| [10. Восприятие объектов](10-восприятие-объектов.md) | облако → стол → кластеры → коробка/цилиндр → класс → устойчивые id (с графиками) |
| [11. Сцена MoveIt](11-сцена-moveit.md) | Planning Scene: объекты, стол, камера, объект в присоске |
| [12. Разметка стола и зоны](12-разметка-стола-и-зоны.md) | **зоны установки: как объявлять, как выбирается зона и место, как добавить свою** |
| [13. Pick & place](13-pick-place.md) | action `/pick_place`: шаги, MoveIt без Python-API, спуск до касания, свой клиент |
| [14. Как проверяли и уроки](14-как-проверяли-и-уроки.md) | изолированные симуляции, проверка на сохранённых кадрах, таблица ловушек |

Рисунки глав 8–14 — [`img/`](img/), их генератор — [`img/make_figures.py`](img/make_figures.py)
(строит по настоящему кадру камеры из симуляции). Схемы — в формате
[mermaid](https://mermaid.js.org/): их рисуют GitHub и VS Code (встроенный
предпросмотр Markdown или расширение «Markdown Preview Mermaid Support»).
В каждой главе есть блоки **«Почитать»** со ссылками на документацию и статьи
по теме.

Знаком **⚠️** отмечены неочевидные места и известные проблемы. Список
актуальных проблем ведётся в [docs/STATUS.md](../STATUS.md).
