# Документация ros2k_ws

Вся документация проекта — **в этой папке** (`docs/`). Других папок с документами нет: корневой
`README.md` только указывает сюда, `CLAUDE.md` в корне — правила для Claude. Рисунки — [`img/`](img/),
устаревшие планы — [`archive/`](archive/), исходники робота R2 для справки — [`reference/`](reference/).

Проект: тележка **quasi_cart** с рукой **xArm6** (присоска + камера на запястье), ROS 2 **Kilted**,
симуляция **Gazebo Sim**. Писали для начинающих: термины объяснены там, где встречаются впервые
(словарь — в [главе 0](00-введение.md)).

## Рисунки и схемы

Рисунки глав 8–14 — [`img/`](img/), генератор [`img/make_figures.py`](img/make_figures.py) (кадр снят
на **прежней сцене из 8 предметов**: алгоритмы те же, но предметы на рисунках 8–15 другие). Рисунки
про обучение модели строит [`img/make_figures_training.py`](img/make_figures_training.py). Схемы — в
формате [mermaid](https://mermaid.js.org/): их рисуют GitHub и VS Code (предпросмотр Markdown или
расширение «Markdown Preview Mermaid Support»).

Знаком **⚠️** в главах отмечены неочевидные места и известные проблемы.

## Правила для документации

- Новые документы — сюда, в `docs/`; рисунки — в `docs/img/`; устаревшее — в `docs/archive/`.
- Любое изменение поведения — строка в [журнале STATUS](STATUS.md) и отметка в [CHECKLIST](CHECKLIST.md).
- Ссылки между документами — относительные (`[NAV.md](NAV.md)`), чтобы работали и на GitHub, и в редакторе.
