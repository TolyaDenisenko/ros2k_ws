# Глава 0. Введение: как устроен проект и как читать эту книгу

Эта книга — путеводитель по workspace `~/ros2k_ws` для тех, кто впервые видит
ROS 2, Gazebo и MoveIt. Каждая следующая глава разбирает одну папку (пакет):
что в ней лежит, что прописано в файлах и **что можно менять**.

## 0.1. Что мы симулируем

Мобильная тележка `quasi_cart` (по умолчанию модель `c2l-v3-scaled`), на её
крыше стоит манипулятор **UFactory xArm6**. На фланце руки — **вакуумная
присоска** и **камера глубины Orbbec Gemini 335Le**. Рядом со
стартовой точкой стоит стол с коробкой `pick_box`, её надо найти камерой
и взять присоской.

Всё работает на **ROS 2 Kilted** (Ubuntu 24.04) и **Gazebo Sim 9**.

## 0.2. Минимальный словарь

| Термин | Что это простыми словами |
|---|---|
| **Workspace** | Папка с исходниками нескольких пакетов, которую собирают вместе. Здесь это корень репозитория `~/ros2k_ws`. |
| **Пакет (package)** | Папка с `package.xml`: единица сборки и поиска файлов (`$(find pkg)`, `ros2 launch pkg ...`). |
| **Нода (node)** | Отдельная программа-участник ROS (например, `robot_state_publisher`). |
| **Топик (topic)** | Именованный канал, по которому ноды пересылают сообщения (`/joint_states`, `/gripper_camera/points`). |
| **Сервис (service)** | Запрос-ответ между нодами (`/vacuum_gripper/set`). |
| **Параметр** | Настройка ноды, задаётся при запуске (`-p имя:=значение`) или в yaml. |
| **Launch-файл** | Python-скрипт, который запускает сразу много нод с нужными аргументами. |
| **URDF / xacro** | Описание робота в XML: звенья (link) и сочленения (joint). xacro — это URDF с макросами и переменными. |
| **TF** | Дерево систем координат: где каждое звено находится относительно других. |
| **Gazebo (gz sim)** | Физический симулятор: мир, гравитация, сенсоры. |
| **Мост ros_gz_bridge** | Переводит топики Gazebo в топики ROS и обратно. |
| **ros2_control** | Слой, через который контроллеры управляют суставами (в симуляции и на железе одинаково). |
| **MoveIt** | Планировщик движений руки (обход препятствий, обратная кинематика). |
| **RViz** | Визуализатор: модель робота, TF, облака точек, маркеры. |

## 0.3. Карта папок

```text
ros2k_ws/                       ← корень = colcon workspace (собирать ТОЛЬКО отсюда)
├── CLAUDE.md, README.md, CART_MODELS.md, INSTALL_RUN.md   ← общая документация
├── docs/
│   ├── STATUS.md               ← журнал изменений и известные проблемы
│   ├── CAMERA_VACUUM_SIM.md    ← как работают камера и вакуум в симуляции
│   └── book/                   ← эта книга
├── src/
│   ├── r2_robot/
│   │   ├── quasi_cart_description/   → глава 1: модель тележки + крепление руки
│   │   ├── cart_xarm_bringup/        → глава 2: главный запуск, мир, мосты, RViz
│   │   └── quasi_camera_description/ → глава 3: камера на запястье
│   ├── xarm_grasping/                → глава 4: анализ захвата, симуляция вакуума
│   ├── xarm_gz_bringup/              → глава 5: рука одна на столе (без тележки)
│   ├── xarm_ros2/                    → глава 6: форк драйвера/описания xArm от UFactory
│   └── object_recognition_msgs/      ← пустой подмодуль, не используется
├── build/ install/ log/        ← результаты сборки, руками не трогать
```

> Совет: собирай только из корня workspace. Папки `src/build`, `src/install`,
> `src/log` лежат в репозитории специально: в каждой только файл `COLCON_IGNORE`,
> чтобы colcon не принял их за пакеты. Не удаляй их. Если после сборки из `src/`
> в них появилось что-то ещё, удали только это лишнее.

## 0.4. Сборка и запуск

```bash
cd ~/ros2k_ws
source /opt/ros/kilted/setup.bash
colcon build --symlink-install          # один пакет: --packages-select <pkg>
source install/setup.bash
ros2 launch cart_xarm_bringup cart_xarm6_gz.launch.py
```

**Когда нужно пересобирать?** Сборка идёт с `--symlink-install`, поэтому файлы в
`install/` — это ссылки на `src/`.

| Что сделал | Нужна пересборка? |
|---|---|
| Поменял существующий `.launch.py`, `.xacro`, `.world`, `.yaml`, `.py`-скрипт | **Нет**, просто перезапусти launch |
| Добавил **новый** файл (скрипт, мир, xacro) | **Да**, `colcon build --packages-select <pkg>` |
| Поменял `package.xml` / `CMakeLists.txt` | **Да** |
| Изменил C++ код | **Да** |

## 0.5. Как читать главы

У каждой главы одинаковая структура:
1. Зачем пакет и с кем он связан.
2. Дерево файлов.
3. Разбор файлов с цитатами кода.
4. **«Что здесь можно менять»** — таблица «Хочу… → файл:строка → параметр».
5. Частые ошибки и упражнения «Проверь себя».

Значок **⚠️ Обрати внимание** отмечает места, где код ведёт себя неочевидно,
комментарии устарели или есть известная проблема.

Если нужно быстро что-то поменять, сразу открывай
[главу 7 «Рецепты»](07-рецепты.md).

## 0.6. Как всё связано при запуске

```text
cart_xarm6_gz.launch.py (глава 2)
 ├─ gz sim + мир cart_table_offline.world (стол, pick_box)
 ├─ xacro cart_with_arm.urdf.xacro (глава 1)
 │    ├─ <robot_model>.urdf.xacro  — корпус тележки
 │    └─ cart-arm.xacro            — рука, присоска, DetachableJoint
 │         └─ xarm_device_macro.xacro (глава 6)
 │              └─ gripper_camera.xacro (глава 3)
 ├─ robot_state_publisher → /robot_description, TF
 ├─ ros_gz_sim create      → спавн робота в точке spawn_x/y/z/yaw
 ├─ контроллеры ros2_control (xarm_controller, глава 6)
 ├─ ros_gz_bridge          → /clock, камера, /vacuum/*
 ├─ depth_image_proc       → /gripper_camera/points
 ├─ vacuum_gripper_sim.py, grasp_analyzer.py (глава 4)
 └─ MoveIt + RViz          (xarm_moveit_config, глава 6)
```
